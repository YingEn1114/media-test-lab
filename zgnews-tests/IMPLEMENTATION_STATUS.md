# 模块化升级交付范围

本轮完成核心模块和有执行证据的业务闭环，以下区分当前实现与需求中的后续扩展，不能将整份需求中的全部细项视作已经完成。

| 模块 | 已实现 |
|---|---|
| 需求中心 | 新建、编辑、删除留痕、版本冲突校验、验收标准、负责人、范围、优先级及标签 |
| AI 用例工厂 | 真实 OpenAI 兼容调用、明确区分演示来源、结构化草稿、单条编辑、版本化代码、删除、重新生成 |
| 独立评审 | 八维权重、后端重算、逐条问题建议、版本/哈希/需求快照、拒绝与过期门禁 |
| Prompt 管理 | 六类默认规则、新版本、历史回滚、使用记录绑定 |
| 代码同步 | 专用本地 bare 仓库、隔离 index 定向提交、代码与 diff、commit/hash、配置分支与作者 |
| 正式用例库 | 原38条人工用例兼容导入、评审与代码一致性校验、设计完整性门禁、人工确认、幂等发布 |
| 查询界面 | 独立入口、默认详情、搜索、状态/域/优先级筛选、分页、中文状态、390px布局 |
| 测试执行 | 冒烟、全量、单条、需求、域、优先级、标签；原子运行槽、取消和崩溃恢复、严格JUnit校验 |
| 缺陷协同 | 失败建卡、RD路由与邮箱、认领、修复说明及commit/PR、RD实际自测、独立QA实际回测、验收关闭 |
| 报告与发件箱 | 完成全量的证据快照、风险结论、默认与自定义收件人/抄送/正文、本地投递、归档、eml下载 |
| 角色与审计 | QA、RD、测试负责人、技术负责人、项目负责人、只读和管理员；服务端令牌、归属校验、操作审计 |
| 迁移与兼容 | SQLite备份、幂等迁移、旧历史只读入口、原元数据不被运行时改写 |

尚未完成的需求扩展：

- 完整的需求业务状态机、复制和归档操作、批量修改/合并候选、单条 AI 重生成和集合覆盖分析。
- 任意复杂 UI/视频/安全/性能自动化生成；目前自动执行只支持六类受限 HTTP/HTML 检查，其他测试设计可保留但不能冒充自动化执行。
- 远程 GitHub/GitLab 推送、PR 创建和远程修复 commit 内容核验；当前版本只同步本地专用资产仓库。
- Prompt 专门试运行面板、图形化逐维评审图、总览趋势图、可配置邮件模板编辑器和模型撰写报告。当前报告和通知采用证据模板。
- 图片/Trace 修复证明上传、挂起/无法复现等全部扩展状态操作、正式报告导出格式及独立报告归档状态机。
- 企业 SSO、令牌轮换/找回、持久任务队列和分布式执行。当前角色账号可由管理员签发，单机执行受数据库运行槽保护。
- 真实 SMTP 外发。本轮按用户选择仅落本地发件箱；不会因环境中已有 SMTP 变量自动外发。

本轮未配置真实 AI 凭据，没有把本地规则演示或 stub 结果标记为真实 AI 验收。

验证：50项平台测试通过；桌面/390px导航22项检查通过；需求→草稿→本地Git→用例筛选→单条执行预选界面路径通过。截图和检查JSON位于本机 `reports/upgrade-final/`、`reports/upgrade-flow/`。
